# oneday 깃북 작성 규칙

`git-for-oneday` 8개 페이지에서 추출하고 나머지 5권으로 공통성을 확인한 규칙이다. 1~4절은 6권 공통, 5절은 git 전용, 6절은 책별 변형이다. 리마스터는 이 규칙을 따르며, 새 문법(`{% hint %}`, `{% tabs %}` 등 GitBook 전용 블록)을 도입하지 않는다.

## 1. 책 구조
- 목차는 `SUMMARY.md` 하나로 관리한다. `# Table of contents` 아래 `* [제목](경로)` 목록, 하위 페이지는 2칸 들여쓰기.
- 파트는 디렉토리 단위(`env/`, `core/`)이며, 파트 대표 페이지는 `<파트>/README.md`.
- 루트 `README.md` 는 책 소개와 `## 실습 목차` 를 가진다. 목차 항목은 `* [제목](경로) : 한 줄 설명`.
- `.gitbook.yaml` 은 없다 (루트 기본값 사용).

## 2. 페이지 구조
1. YAML frontmatter `description: >-` 로 페이지 요약 한두 문장.
2. frontmatter 뒤 빈 줄 2개, 이어서 `# 페이지 제목` (페이지당 1개).
3. `## N. 섹션` → `### N-M. 소섹션` → `####` 소제목 순서. 번호는 페이지 내에서 중복 없이 증가한다.
4. 명령어를 다루는 소섹션 제목은 명령어를 백틱으로 감싼다. 예: ``### 2-1. `git revert` ``
5. 섹션 사이에는 빈 줄 2개를 둔다.

## 3. 블록 요소
| 요소 | 규칙 | 예 |
|---|---|---|
| 부연 설명 | 제목 바로 아래 `>` 인용 한두 문장 | `> 과거에 수행했던 ...` |
| 용어 정의 | `> **용어** : [영문](링크) 설명` | intro.md 1-1 |
| 명령어 표 | 헤더 `\| 명령어 [옵션] \| 설명 \|`, 인자는 `[branch]` 처럼 대괄호 | branch.md 1-1 |
| 코드 블록 | 실행할 셸 명령과 기대 출력은 ```` ```bash ````. 파일 내용(md, csv, .gitignore)은 언어 없는 ```` ``` ````. 단, 셸 문법 파일(`.bashrc` 등) 내용은 `bash` 허용 | |
| 코드 내 주석 | `# 한국어 설명` 으로 단계를 구분 | |
| 실습 지시 | `#### **<실습>** 할 일` | version.md 1-1 |
| 결과 확인 | `#### 실습 결과 확인` + 기대 `git log --all --graph --oneline --decorate` 출력 | |

| 목록 | `*` 사용, 하위 항목은 2칸 들여쓰기 + `-` | |

## 4. 문체
- 한국어 경어체 `~합니다`, `~입니다` 로 통일한다 (`~이다` 혼용 금지).
- 명령어, 파일명, 브랜치명은 백틱으로 감싼다.
- 영문 용어는 처음 등장 시 `한국어(English)` 또는 `English(한국어)` 로 병기한다.

## 5. 실습 시나리오 규칙
- 실습 환경: `data-engineer-basic-training` 레포의 `ubuntu` 컨테이너, 작업 경로 `/home/ubuntu/work/git`.
- 예제 데이터: 넷플릭스 오리지널 한국 드라마 목록 (`README.md`, `YYYY.csv`).
- 커밋 메시지 형식: `[태그] 메시지` (예: `[2019] 작품`, `[OLD] 스타일`, `[충돌] 파일 해소`).
- 앞 페이지의 실습 결과가 다음 페이지의 시작 상태가 된다 (core/README → version → branch 순서로 이어짐). 기대 출력은 이 연속성과 일치해야 한다.

## 6. 책별 변형 (위반으로 보지 않음)
| 책 | 허용 변형 |
|---|---|
| git | `#### **<실습>**`, `#### 실습 결과 확인` |
| linux | 정답 접기 `<details>`, 줄바꿈 `<br>` |
| mysql | `sql` 블록, `\| 문/표현식 \| 설명 \| 예제 \|` 구문 표 |
| python, hadoop | `python` 블록 |
| docker | `env/` 파트 없음, 스크린샷 위주 설치 가이드, 섹션 번호 `1.1` 형식 |
