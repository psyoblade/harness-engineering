# 리뷰어 공통 출력 형식

code-review-lexical, code-review-platform, code-review-advisor 는 최종 응답을 이 형식으로 반환한다 (파일을 만들지 않는다).

## 형식

```
## 관점: <lexical|platform|advisor>

### 원칙 점검
- 원칙 N: ✅|⚠️|❌|해당 없음 — 근거 1줄

### 지적
- 심각도: 🔴 Critical | 🟠 Major | 🟡 Minor
  위치: [파일명:라인번호]
  구분: 신규 | 기존
  신뢰도: 0~100
  내용: 무엇이 문제인지 1줄
  근거: diff 나 코드에서 확인한 사실 1줄
  제안: 수정 방향 1줄
```

지적이 없으면 `### 지적` 아래에 `지적 없음` 한 줄.

## 규칙
- 위치는 source 버전 기준이다. 라인번호는 `git show <SOURCE_SHA>:<경로>` 로 확인한 값을 쓴다 (verify-locations.sh 가 검사한다).
- 구분: 이 PR 이 만든 문제면 `신규`, 이 PR 이 건드리지 않은 기존 코드면 `기존`.
- 신뢰도: 근거를 코드에서 직접 확인했으면 80 이상, 추정이면 80 미만. 80 미만은 최종 결과에서 빠진다.
- 근거 없는 추측성 지적, 린터·포매터가 잡을 스타일 지적은 쓰지 않는다.
- 저장소에 CLAUDE.md 가 있으면(REPO_CLAUDE_MD=yes) 그 규칙 위반도 지적한다. 근거에 해당 규칙을 인용한다.
